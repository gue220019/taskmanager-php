# Anforderungen

## ANF-01 Aufgabe hinzufügen – Selin

Das System soll ermöglichen, dass eine neue Aufgabe mit Titel erstellt werden kann.

Akzeptanzkriterium:
Eine Aufgabe besitzt einen Titel und ist nach dem Erstellen zuerst nicht erledigt.

## ANF-02 Aufgaben anzeigen – Lejla

Das System soll gespeicherte Aufgaben anzeigen können.

Akzeptanzkriterium:
Alle gespeicherten Aufgaben werden als Liste ausgegeben.

## ANF-03 Aufgabe löschen – Zümra

Das System soll ermöglichen, dass eine Aufgabe gelöscht werden kann.

Akzeptanzkriterium:
Nach dem Löschen ist die Aufgabe nicht mehr in der Aufgabenliste vorhanden.

## ANF-04 Aufgabe erledigt markieren – Zümra

Das System soll ermöglichen, dass eine Aufgabe als erledigt markiert werden kann.

Akzeptanzkriterium:
Nach dem Markieren besitzt die Aufgabe den Status erledigt.
