# TaskMaster – PHP Taskmanager

TaskMaster ist ein einfaches PHP-Projekt zur Verwaltung von Aufgaben.

Das Projekt wurde nach dem Softwareentwicklungsplan umgesetzt. Dabei wurde auf Rückverfolgbarkeit zwischen Anforderungen, Branches, Commits und Tests geachtet.

## Funktionen

- ANF-01 Aufgabe hinzufügen
- ANF-02 Aufgaben anzeigen
- ANF-03 Aufgabe löschen
- ANF-04 Aufgabe erledigt markieren

## Team

PTM 1 = Selin --> ANF-01 Aufgabe hinzufügen, Setup und allgemeine Dokumentation 
PTM 2 = Lejla --> ANF-02 Aufgaben anzeigen 
PTM 3 = Zümra --> ANF-03 Aufgabe löschen und ANF-04 erledigt markieren
